# Validation checklist

```text
□ Correct population / eligible set?
□ Time range and timezone match the question?
□ Baseline appropriate (not yesterday vs day-before by default)?
□ Numerator and denominator same grain?
□ Data complete / fresh enough?
□ Could missingness explain the move?
□ Could seasonality explain it?
□ Could one segment dominate (whale / one tenant)?
□ Simpson / mix shift checked?
□ Did the metric definition or tracking change?
□ Reproducible (saved card / one sandbox script)?
□ Correlation stated as correlation?
□ A competing explanation still standing?
□ Adversarial query run (RCA)?
```

If a box is unknown, say unknown.
