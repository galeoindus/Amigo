# Evidence language

Do not conflate:

| Word | Allowed when |
|---|---|
| Observation | you measured it |
| Correlation | two series moved together |
| Evidence | a test supported or killed a hypothesis |
| Likely explanation | surviving hypothesis, alternatives listed |
| Causal conclusion | mechanism **and** complementary slice **and** validation passed |

Default to **likely explanation**. Causal conclusions are rare.

## Adversarial query (required)

Whatever you believe, run one query that should be **false** if you are right. If it survives, you do not have a likely explanation yet.

## Mix effects

An aggregate can move purely because the **mix** of sub-populations changed, even when every sub-population moved the other way (Simpson's paradox). A rate is a weighted average: check both the within-segment values and the segment weights before attributing the aggregate move to any single segment.
