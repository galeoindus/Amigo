## How the agent should use this list

- Start with the platform's official docs for the project actually in front of you; don't cargo-cult this list into every task.
- Verify the release/version, deprecation notices and supported APIs at the time of change.
- Use standards for normative guidance and vendor docs for implementation details.
- Prefer directly relevant docs over search-result snippets. Do not present a recommendation as an official requirement unless the source actually says so.
- When a factual recommendation materially affects architecture/security, add the relevant link and state the date checked.
